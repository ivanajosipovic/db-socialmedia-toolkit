Social Media Toolkit

Kampagne aufklappen → Beitrag aussuchen → „Text kopieren“ → posten. Fertig!

So funktioniert’s

LinkedIn / Facebook: Neuen Beitrag erstellen, kopierten Text einfügen, ggf. Bild anhängen, veröffentlichen.

Instagram: Erst das Bild auswählen, dann den Text als Bildunterschrift einfügen.

WhatsApp-Status: Status → Text oder Foto wählen, kopierten Text einfügen.
